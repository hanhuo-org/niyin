# ⚡ 如何开启浏览器显卡加速，让汉火古音拟音提速 3~5 倍

汉火三代古音工作台（`https://yin.hanhuo.org/`）完全在你的浏览器本地完成古音合成，**诗文与参考人声无需上传云端**。

当你打开网站时，页面右上角会自动显示当前的运行方式：
- **`⚡ 显卡加速开启`（绿色）**：已启用浏览器显卡硬件加速，整首四句唐诗通常只需 **约 8~13 秒** 即可生成完毕，且丝毫不影响电脑流畅度。
- **`⚙ 纯处理器推理`（金色）**：当前未检测到可用的浏览器显卡接口，系统已自动回落到处理器计算，功能与音质完全一致，但生成速度会慢 3~5 倍。

如果你的电脑配有独立显卡或主流核显，但右上角仍显示「纯处理器推理」，按下面对应系统的简单步骤设置一次即可开启显卡加速：

---

## 一、Windows（Chrome / Edge 浏览器）

最新版 Chrome（113+）和 Microsoft Edge 默认已经开启显卡加速。如果未生效，只需检查两处：

1. **开启浏览器硬件加速**
   - Chrome：打开设置 → `系统` → 打开 **「使用图形加速功能（如果可用）」**
   - Edge：打开设置 → `系统和性能` → 打开 **「使用图形加速功能（如果可用）」**
2. **确认渲染后端未被改为 OpenGL**
   - 地址栏输入并打开 `chrome://flags/#use-angle`（Edge 为 `edge://flags/#use-angle`）
   - 将该项设为 **Default** 或 **D3D11**（不要选 OpenGL）
   - 点击右下角 **Relaunch（重启浏览器）**，重新打开网站即可看到 **`⚡ 显卡加速开启`**。

> 小贴士：笔记本如果是双显卡（核显 + 独显），可在 Windows「设置 → 系统 → 显示 → 图形」中把浏览器设为 **高性能（独显）**，合成速度会更快。

---

## 二、macOS（Apple Silicon M1/M2/M3/M4 或 Intel Mac）

- **推荐使用 Chrome 或 Edge**：打开 `https://yin.hanhuo.org/` 默认即走 Apple Metal 显卡加速，无需任何手动配置。
- **Safari 浏览器**：需升级至支持 WebGPU 的较新版本；如较旧版本暂不支持，系统会自动使用多核处理器平稳运行。

---

## 三、Linux（Chrome / Chromium / Edge 浏览器）

Linux 桌面版 Chrome 默认关闭了部分显卡加速开关，**需要同时开启下面 3 个开关**（缺一不可）：

1. 地址栏输入 `chrome://flags/#enable-vulkan` → 改为 **Enabled**
2. 地址栏输入 `chrome://flags/#enable-unsafe-webgpu` → 改为 **Enabled**
3. 地址栏输入 `chrome://flags/#ignore-gpu-blocklist` → 改为 **Enabled**
4. 点击右下角 **Relaunch** 重启浏览器，再强制刷新网页（`Ctrl + F5`）。

> **前置检查**：确认系统已安装对应显卡的 Vulkan 驱动：
> - **NVIDIA**：官方闭源驱动已自带 Vulkan；
> - **AMD / Intel 核显**：Ubuntu / Debian 可执行 `sudo apt install mesa-vulkan-drivers`，Arch 可安装 `vulkan-radeon` 或 `vulkan-intel`。

---

## 四、手机与平板设备

- 目前部分手机浏览器暂未开放或默认限制 WebGPU，网站会自动切换为 **纯处理器推理**，同样可以完整体验上古、中古、近古三代拟音、全韵试听与单字调音。
- 若希望长诗合成更快，建议优先使用电脑端 Chrome / Edge 浏览器访问。

---

## 五、常见问题排查（还是没亮绿灯怎么办？）

1. **必须通过 `https://` 打开网站**：浏览器安全策略规定，只有 `https://` 加密地址（或本机 `localhost`）才允许调用显卡加速；局域网通过 `http://` 访问会被浏览器自动屏蔽显卡接口。
2. **检查显卡驱动是否过旧**：Windows 建议更新 NVIDIA / AMD / Intel 官方显卡驱动；虚拟机或远程桌面（RDP）环境通常没有真实显卡直通，会自动使用处理器推理。
3. **验证浏览器是否真正启用了硬件加速**：
   - 在地址栏打开 `chrome://gpu`，查看 `WebGPU` 是否为 **`Hardware accelerated`**（Linux 还需确认 `Vulkan` 为 **`Enabled`**）。
4. **查看精准诊断原因（进阶）**：
   - 在汉火古音页面按 `F12` 打开浏览器控制台（Console），找到 **`[Hanfire] 引擎就绪:`** 这一行，里面的 `gpuDiag` 字段会直接告诉你当前是已命中哪块显卡，还是因哪一项设置回落到了处理器模式。
5. **一键切换显卡 / 纯处理器模式与自动释放显存**：
   - 若笔记本/轻薄本需要静音省电或降低显卡负载，**直接点击页面右上角 `⚡ 显卡加速开启` 徽章**即可一键切回「纯处理器模式」（再次点击可立刻切回显卡加速，无需重新下载语音库）。
   - 页面闲置超过 3 分钟后，系统也会自动释放显卡显存占用，下次点击合成时自动从本地缓存秒级恢复。
