## 一、核心架构定型：四层解耦 × 真人活腔残差范式

历经 V6 → V8 → V9.0 → V9.6 六轮真听迭代，`hanfire_sing` 确立了区别于现代流行 SVS 与纯规则合成的**古诗文唱吟底层范式**：

```
古诗文文本 + 朝代 (zh / mc / em / oc)
  │
  ▼ [1. 历史音韵编译器 · hanfire_sing_phonemes.py]
    • 严格按中古《广韵》/ 近古《中原音韵》判定四声与阴阳清浊（绝不用现代普通话判入声）
    • 100% 对齐 OpenCpop 词表（opencpop_clean.txt）与古诗文上下文多音词覆写
  │
  ▼ [2. 真人活腔残差 × 五声移阶引擎 · shijing_v9_engine.py / guwen_v9_engine.py]
    • F0(t) = 真人母带实录 RMS 净化活腔残差 + 中古/近古五声合法移阶
    • 零词内 SP + 清擦音足长(88~115ms) + 口腔闭塞跨声门压基频微谷(-1.45/-1.75st)
    • 四言神圣节拍律（诗经） / 平长仄短+入声利落+句末虚词大拖腔（古文/辞赋）
  │
  ▼ [3. 双声部 44.1kHz 纯棚录 DiffSinger 底座]
    • 女声：hanfire_sing_base (OpenCpop 5.2h, 40k steps, lynxnet2 + shallow reflow T_start=0.4)
    • 男声：hanfire_sing_male (M4Singer 6男声 10.35h, 40k steps, 同架构同词表)
  │
  ▼ [4. 声码器与响度保护 · PC-NSF-HiFiGAN 44.1kHz 2025.02]
    • 零动态压缩，保留 ~7dB 真人自然强弱起伏，峰值保护 Peak <= 0.72，底噪 <= -78dB
```

## 二、声学与音乐学核心发现（直接源自母带实测）

### 1. 《诗经》唐调六音五声八度晶格
对全部 4 首唐调《诗经》母带（`t01 关雎`、`t13 采薇`、`t14 无衣`、`t15 蒹葭`）做高精度 `pyin` 频谱统计发现，它们共享**同一套六音五声八度晶格**：
- `3₁ (-5.5st)` — **`5₁ (-2.5st, 主落韵徵音)`** — `6₁ (-0.5st)` — **`1 (+2.5st, 宫轴)`** — `2 (+4.5st)` — `3 (+6.5st)`。
- **四言神圣节拍律**（实测 `t13《采薇》` vs `t15《蒹葭》`）：`白(0.33) 露(0.40) | 为(0.80) 霜(0.64)` vs `薇(0.40) 亦(0.35) | 作(0.90) 止(0.60)`——重拍第 3 字哪怕是古入声（如 `作/曰/莫/一/淑/室`），在四言吟诵中仍保留 **84%(MC) ~ 94%(ZH/EM)** 的重拍锚定，绝不可粗暴切短至 `0.45s`。

### 2. 唐调古文与辞赋的三阶/宫轴滚诵律
实测 `t09《兰亭集序》`、`t16《陋室铭》`、`t18《前赤壁赋》` 棚录母带，发现古文/辞赋完全不同于《诗经》的固定四拍曲调，而是**五声诵腔 + 句末落韵（Recitative-Cadence）体系**：
- **`t09《兰亭集序》`（书斋清雅骈散调）**：`6₁(-3st) 低叙` — `1(0st) 中宫咏叹` — `5(+5st) 清亮领起` 三阶流转，句末虚词（`也/矣/乎/哉/焉/耳/兮`）作 `0.78~0.98s` 大拖腔留余韵。
- **`t16《陋室铭》`（唐调铭文沉雄顿挫调）**：`3₁(-4.8st) — 5₁(-2.8st) — 1(0st) — 2(+2.5st)` 四级骈偶双拱（起句悬平 `+1.8→0st`，承句落徵 `+2.0→-3.2st`，转折沉底 `-4.8st`）。
- **`t18《前赤壁赋》`（唐调辞赋大开大合长短句调）**：低五度 `-6.8st` 苍茫蓄势 → 长句稳锁 `0.0st` 主宫轴如江水滚诵、重点实词扬锋 `+2.5st` → 句末落徵 `-4.5~-6.7st`，可无缝驾驭 3~15 字参差长短句。

### 3. 「窈窕淑女 / 之子于归」底层四重根因攻坚复盘
这是本轮最具价值的声学攻关，最终用 **女声 6/6 + 男声 6/6 跨未知随机种子（`101/202/303`）盲测** 证明 100% 源自底层物理机制而非随机种子运气：
1. **声部第一换声点效应**：OpenCpop 女声在 `300~311Hz (D4–Eb4)` 存在明显气声换声区；将调式 B 基准回归原唱 `238Hz` 后，第 3 句后两字稳落 `277Hz (C#4)` 纯真声实音区。男声同理按各歌手原生音域锁定在换声点以下 `70~90Hz+`。
2. **`FastSpeech2Acoustic` 的 `SP` 乐句重起效应**：任何词内 `SP`（即使仅 `15ms`）都会让编码器注意力判定为“新乐句重起”，强行在后字注入 `+3.5dB` 高频重音，且事后波形拉低音量也消不掉音色上的“强调感”。**唯一正解是彻底零词内 `SP`。**
3. **口腔闭塞跨声门压基频微谷（物理成阻建模）**：实测真人发长元音后的鼻音 `n/m` 与塞音 `b/p/d/t/g/k` 时，声门上下气压差下降必然在声母闭塞期产生短促基频微谷。给足 `102~108ms` 声母时长并在平滑**之后**仅于声母帧叠加 `-1.45 / -1.75st` Hanning 微谷，不插 `SP` 即可迫使扩散解码器清晰成阻。
4. **多章母带交叉核验**：核对 `t01《关雎》` 全部 5 章后发现第 1 章「女」的 `+1.4st` 上拱仅是冷起嗓偶发，第 2~5 章全部为平稳同音平托 `do→do`；同时用解耦的 `(f0_start, f0_end, tpl_tone, target_dur_s)` 彻底清除了「洲 4.32s / 霜 4.75s」前字串音深坑。

## 三、已证伪并永久废弃的弯路（反面教材警示录）

| 废弃方案 | 失败机理与实测后果 | 最终替代方案 |
|---|---|---|
| **V9.0 纯数学贝塞尔抛物线 F0 + 正弦颤音** | 活人微腔 `std_df0` 暴跌 36%（`0.164 → 0.105`），听感立刻变机械电子唱腔 | 100% RMS 门限净化真人母带活腔残差 + 平仄五声平移 |
| **动态响度压缩器 (`balance_voiced_loudness`)** | 自然强弱起伏从 `7.5dB` 压扁到 `3.0dB`，丢失诗意呼吸感 | 彻底撤除，仅保留整曲无损峰值保护归一化 (`Peak <= 0.72`) |
| **词内插 `SP` (`130ms→32ms→15ms`) + 事后音量压制** | `130ms` 碎拍，`15~32ms` 触发 `FastSpeech2Acoustic` 高频重音“突然强调” | 零词内 `SP` + 声母帧 Hanning 跨声门压基频微谷 |
| **强行抬升「淑」`+2.1st` 接高音** | 把「淑」推出五声音阶（`D4-E4-F#4` 中硬插调外 `F4`）直接跑调 | 严格守五声调内 + `sh` 给足 `115ms` 清晰擦音 |
| **用 6.15min 本地干声 + Whisper 标注全量解冻微调男声 (`hanfire_tang_local`)** | Whisper 在古文大面积幻觉（`山不在高→尊古在高`、`斯是陋室→是是老师`），4000 步全量微调把 `sh/c/s/j/zh` 辅音彻底毁掉 | 采用 6 位 M4Singer 纯棚录男声 `10.35h` + 毫秒级 TextGrid 从零满训 40k 步 `hanfire_sing_male` |
| **女声硬降 `--gender=-0.5` 冒充男声** | 咬字虽清晰但共振峰闷虚，明显“伪男声”感 | 原生纯棚录男声底座 (`m4_bass1` / `m4_tenor7` / `m4_tenor6`) |
| **Colab 上用默认 `snapshot_download` 拉取 1.4 万小文件** | 触发 HF 单文件限速仅 `3.4 files/s`，白烧 1 小时 A100 | 32 线程 `requests.Session` 直连 HTTP 断点续传（`20~40 files/s`，3 分钟拉完） |
