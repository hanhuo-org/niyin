🔥 汉火古音 · 为什么这样设计？

汉语古音拟音最大的难点，不是“把国际音标字母拼读出来”，而是同时守住历史音韵学的严谨性与真人朗读的自然韵律。 汉火古音将上古、中古、近古三代音韵规律与人声合成深度融合，重点攻克古音合成最常见的四大顽疾：多拍裂音、押韵漂移、开闭口混乱与杂音断句。（页面中所有带虚线下划线的音韵术语，鼠标悬浮均可查看白话释义）

一、为什么坚持「一字一音」？（单核 4 槽音节结构）

学术拟音里常出现复杂的多合元音或复辅音（如上古 keau / ʔiei / ɣiwəi）。如果直接按字母逐个拼接发音，一个汉字往往会被拖裂成两三拍（例如把「舉」读成 ji+ü、「須」读成 思+与、「俱」裂成 gui、把句首的「安」读成 安安）。

  • 单核 4 槽严格归并：每个汉字在发音前都固定归并为一个完整音节：[声母 | 介音 | 唯一韵腹 | 韵尾]，严守诗词格律一字一拍。
  • 简繁古籍全覆盖零漏字：内置双向简繁与古籍异体字对应（如 滾→袞、裏→裡、間→閒、爲→為），保证任意诗文不吞字、不漏字。
  • 魚/虞分流防裂音：中古精组魚虞（須/徐/聚）与见组魚韵（舉/去/渠）采用干净的纯撮口发声，而见组虞韵（俱/拘/驅）保持圆唇收束，彻底杜绝双音裂变。
  • 句首零声母自然起音：句首开口零声母字（如 安/庵/翁/哀）直接平稳起音，不再把句首「安」拉裂成两声。

二、为什么能「真押韵」？（三代韵核锁定与舒长入短）

如果用现代普通话去近似拼读古音，唐诗与《诗经》原本严丝合缝的押韵就会大面积失效（例如「絕/滅/雪」「光/霜/鄉」「庵/仙/錢」听起来互不押韵）。

  • 上古 30 韵部阴阳入对转（王力体系）：清晰区分 -m/-n/-ŋ 与 -p/-t/-k，真部 人/民/信 归 -in，元部 -r 与 -n 自然通押。
  • 中古 16 摄 245 韵类精准归核：严格锁定同韵字主元音，使 先/仙 入声（絕/滅/雪）同押 -jɛt，侵/緝 入声（笠）保持清晰细音不退化为「了」。
  • 近古明清 19 韵与五声：保留独立短入声，还原寒山二等未颚化（間/顏 押 -an）及明代 -m→-n 演变（庵/仙/錢 同押）。
  • 舒长入短格律节奏：句末舒声韵脚自然舒展延长；入声韵脚保持短促利落，绝不把短入声拖成长音。

三、开闭口、四呼与入声塞尾的精细雕琢

古音听起来是否纯正自然、不像“怪味普通话”，关键藏在开口/合口/细音（四呼）、双唇闭口韵（-m/-p）与尖团/清浊这些细腻的发音特征里：

  • 影母与云母按呼/等精准分派：洪音开口（安/哀/翁）保持纯净零声母，绝不给「笠翁」挂出多余的 y 杂音；合口（烏/王/為）轻带圆唇；细音（衣/雨/雲）轻带齐齿滑音，消除「細雨」间的停顿空洞。
  • 双唇闭口韵 -m / -p：上古侵談与中古深咸摄（心/林/南/鹽/笠/立）保留双唇自然闭拢收尾，与舌尖 -n/-t 清晰区分。
  • 唯闭短促入声（不弹音）：汉语入声塞尾 -p/-t/-k 讲究「唯闭不除阻」——只收口截断气流而不向外弹气，听感紧促干净，绝不发出刺耳的“咋可”杂音。
  • 近古尖团分明 & 中古崇母擦化：明清雅音保留尖音（清/秋/千/酒/仙）与团音（輕/江）对立及微母、疑母；中古崇母止摄仄声（士/仕/事）遵循盛中唐擦化与浊上变去规律，避免「寒士」读断。

四、纯净人声、本机直算与众包快速勘误

  • 原生棚录参考声，纯净防破音：采用未经变速拉扯的录音室纯干声作为音色基准，彻底消除传统古音合成常见的“句首杂音”“电子金属声”与刺耳削波破音。
  • 稳定韵律，告别随机断句：整套发声过程采用确定性节奏控制，不会因为随机波动而在诗句中间突然卡壳断句，每次生成都稳健如一。
  • 直接在你的设备本地运行，隐私安全：所有古音合成都在你的浏览器本地完成（有显卡自动启用显卡加速，无显卡自动回落多核处理器），诗文与自定义参考人声均无需上传云端；首次加载语音库后会自动留存本机，下次打开瞬间就绪。
  • 众包听审，单字快速迭代：当你发现某个字读音不够准确，可直接点击汉字卡片实时调音试听，并一键提交纠正建议；站长采纳后只需更新词典即可快速全站生效。

⚡ 五、如何开启浏览器显卡加速（提速 3~5 倍）

本工作台支持直接调用你电脑的显卡进行本地古音合成。右上角显示 「⚡ 显卡加速开启」 时，整首四句唐诗仅需约 8~13 秒 即可生成；若显示 「⚙ 纯处理器推理」，说明浏览器尚未开放显卡加速接口，按下面对应系统开启一次即可：

🪟 Windows（Chrome / Edge）
  • 打开浏览器设置 → 系统 → 开启「使用图形加速功能」。
  • 地址栏打开 chrome://flags/#use-angle（Edge 为 edge://flags/#use-angle），确认设为 Default 或 D3D11，重启浏览器。
  • 双显卡笔记本可在系统「显示 → 图形」设置中将浏览器指定为高性能独显。
🍎 macOS（M 系列 / Intel）
  • 使用新版 Chrome / Edge 打开本站默认即自动启用显卡加速，无需额外设置。
  • 若用旧版浏览器或手机访问，系统会自动平滑切换到多核处理器运行，音质完全一致。
🐧 Linux（Chrome / Chromium / Edge）
  • Linux 版浏览器默认关闭部分开关，需在地址栏同时开启以下 3 项后重启浏览器：
  • chrome://flags/#enable-vulkan → Enabled
  • chrome://flags/#enable-unsafe-webgpu → Enabled
  • chrome://flags/#ignore-gpu-blocklist → Enabled
🔍 常见排查小贴士
  • 请确保通过 https:// 网址访问（浏览器会屏蔽 http:// 网页调用显卡）。
  • 改完开关后务必点击右下角 Relaunch 重启浏览器，再按 Ctrl+F5 刷新本页。
  • 在地址栏输入 chrome://gpu，确认 WebGPU 显示为 Hardware accelerated（Linux 需同时确认 Vulkan 为 Enabled）。
